Sample Subway – Nuclear Pressure Tube Sampling System

An embedded remote-controlled device engineered for Canadian Nuclear Laboratories (CNL) to retrieve and weigh 30–80 mg metal samples within 4-inch internal diameter, 15-foot nuclear pressure tubes.

01 // SYSTEM OVERVIEW & SPECS

// PROJECT SCOPE

Electromechanical remote sampling tool engineered for Canadian Nuclear Laboratories (CNL) to collect [ 30–80 mg ] metal samples from 4-inch ID, 15-foot nuclear pressure tubes for hydrogen embrittlement destructive testing.

// DESIGN CONSTRAINTS

Dual-orientation operation (horizontal/vertical), complete retrievability, zero operator exposure, self-contained power, and wireless telemetry within a 10-minute operational window.

// SYSTEM ARCHITECTURE BREAKDOWN

Processing & Logic

ESP32-WROOM-C3 Microcontroller (C++ / Arduino IDE Firmware)

Movement & Recovery

Dual 12V N20 200 RPM Gearmotors (Horizontal Drivetrain) + Custom Winch Spool & Paracord Tether (Vertical / Emergency Failsafe)

Actuation & Scraping

JGB37-520 12V 7RPM High-Torque Gearmotor + BTS7960 43A High-Power H-Bridge Driver + MGEHR1212 Lathe Tooling

Analog Signal Chain

100g Strain-Gauge Load Cell + HX711 24-bit Differential ADC Module

Power Architecture

Custom 3S1P Li-Ion Battery Pack (3x Molicel 21700 P42A Cells, 11.1V Nominal, 4500mAh) + 3S 40A BMS Board + LM2596 Buck Regulator (5V/3.3V Logic)

02 // ENGINEERING METHODOLOGY & TARGET SPECS

CLIENT REQUIREMENTS MATRIX

Needs Analysis & Prioritization

Transformed CNL client statements into prioritized engineering design criteria:

  1. Safety & Exposure Limitation: Self-sealing sample containment.
  2. Complete Removability: Winch tether emergency recovery failsafe.
  3. Payload Precision: Target sample extraction of [ 30–80 mg ].
  4. Telemetry & Stage Reporting: Real-time Bluetooth mass feedback.
  5. Modularity & Envelope: Length < 4 ft, diameter < 4 in.
  6. Self-Contained Power: Onboard high-current Li-ion battery pack.
  7. Operational Speed: Cycle completion within < 10 minutes.
EDS MATRIX

Engineering Design Specifications

Functional Requirements

  • Mass collection: [ 30–80 mg ] (verified via scale feedback)
  • Complete removability: Yes (100% retrieval guarantee)
  • Enclosed sample: Yes (Self-sealing spring lid)
  • Distance traveled: [ 15 ft ] inside pressure tube
  • Cycle time: [ < 10 min ] total deployment

Physical & Safety Constraints

  • Outer diameter: [ < 4.0 in ] envelope
  • Total tool length: [ < 4.0 ft ]
  • Total tool mass: [ < 5.0 kg ] man-portable
  • Operator contact: Zero manual touch on radiation tooling
DECISION MATRIX

Concept Evaluation & Trade-off Justification

Evaluated 4 global architectural concepts (Sample Subway, Pipe Worm, Pneumatically Deployable Tool, and Flywheel Flinger) against weighted client design criteria.

Selection Justification: The Sample Subway scored highest in the decision matrix due to superior traction control in dual orientations (horizontal & vertical), a simplified winch recovery failsafe, and predictable mechanical scraping kinematics compared to pneumatic or inflatable tube crawlers.

03 // KINEMATICS & MECHANICS

KINEMATIC PROFILING

Kinematic Extraction Profiling

Detailed cross-sectional geometric overlap analysis in OnShape between the motor armature path and the 4.05-inch pipe wall, designing a precise cut path to extract a target mass of [ 65 mg ] (within the [ 30–80 mg ] spec window).

CONTAINMENT MECHANISM

Self-Sealing Containment Mechanism

Spring-loaded sliding lid container. Upon insertion into the tool head, catch pins hold the lid open; upon removal, internal compression springs force the lid shut, isolating the sample and eliminating human contamination.

DRIVETRAIN ITERATIONS

Drivetrain Traction Iterations

Modular wheel mounting evolution—progressing from raw 608 steel bearings (high slip) to 3D-printed TPU sleeves, and finally compressible rubber traction bands to maintain high normal force against internal tube walls under high scraping torque.

04 // HARDWARE & SIGNAL CHAIN

POWER ARCHITECTURE

Power Tree Topology

Unregulated 12V high-current bus powering the BTS7960 and N20 motor drivers. Down-regulated via LM2596 buck converter to 5V VIN for the ESP32, which supplies 3.3V logic rails.

[ 3S1P Li-Ion Pack: 11.1V / 4500mAh ]
├── Unregulated 12V High-Current Bus ➔ BTS7960 & N20 Motors
└── LM2596 Buck Regulator ➔ 5V VIN ➔ ESP32 ➔ 3.3V Logic Rails
ANALOG INSTRUMENTATION

Analog Signal Chain

Wheatstone bridge load cell interfaced with the HX711 24-bit ADC. Implemented twisted-pair differential wiring to reject electromagnetic interference (EMI) generated by adjacent DC motors inside the chassis.

[ 100g Strain Gauge Wheatstone Bridge ]
└── Twisted-Pair Differential Wiring (EMI Noise Rejection)
└── HX711 24-bit Differential ADC ➔ ESP32 SPI/GPIO

05 // EMBEDDED C++ FIRMWARE

Custom C++ firmware running on the ESP32-WROOM-C3 microcontroller delivering real-time noise suppression, thermal drift compensation, and Bluetooth serial data telemetry.

NOISE SUPPRESSION

100-Sample Moving Average Filter

Reduces raw sensor fluctuation from [ ±100 mg ] down to an acceptable noise floor of [ ±9.5 mg ].

float applyMovingAverage(float newSample) {
  sum -= samples[index];
  samples[index] = newSample;
  sum += newSample;
  index = (index + 1) % 100;
  return sum / 100.0f; // Noise floor ±9.5 mg
}
DRIFT COMPENSATION

Time-Based Creep Drift Compensation

Firmware routine executing every 30 seconds. If measured drift is below [ 10 mg ], the system automatically re-tares the scale to offset mechanical creep and thermal variance.

if (millis() - lastCheckTime >= 30000) {
  float drift = fabs(currentWeight - baselineWeight);
  if (drift < 10.0f) {
    autoTareSystem(); // Auto-tare thermal creep
  }
}

Telemetry Protocol

ESP32 Bluetooth Serial (RFCOMM) streaming formatted CSV packets (Timestamp, Raw Mass, Filtered Mass, Creep State) to remote monitors.

07 // POST-MORTEM & FUTURE ROADMAP

01

Root Cause Failure Analysis

High scraping torque during pipe engagement induced motor stalls. Peak stall current spikes exceeded the 3S BMS threshold, tripping overcurrent protection and cutting system power.

02

Custom PCB Design Roadmap

Transitioning from discrete breakout modules and point-to-point breadboard wiring to a unified 2-layer custom PCB with dedicated power planes and high-current traces.

03

Mechanical Safety Integration

Engineering a calibrated shear notch on the lathe bit holder. Under binding torque, the bit holder snaps safely, preventing motor stall current spikes and ensuring smooth recovery via winch failsafe.
