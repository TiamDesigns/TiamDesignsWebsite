## 2024-10-27 - Centralized Content-Security-Policy Configurations
**Vulnerability:** The Content-Security-Policy (CSP) is hardcoded in over 10 different files (HTML files and configuration files for Vercel and Netlify), increasing the risk of configuration drift and creating overly restrictive or misconfigured security policies.
**Learning:** Hardcoding security policies across multiple entry points makes updates error-prone and tedious. Missing a file when updating the CSP (e.g., adding a legitimate third-party service) can lead to broken functionality or insecure bypasses in certain environments.
**Prevention:** Consider centralizing the CSP generation using a build step or a shared configuration module that injects the policy into HTML files and deployment configurations dynamically to ensure consistency.
